Paper loss-stop persistence: when mark-to-market equity reaches the configured loss limit, paper mode writes an atomic owner-only `data/paper-risk-stop.json` latch. A later process start loads it before model calls; malformed state or a market mismatch fails startup closed. If saving fails, the current process stays stopped and reports that it must not be restarted before storage is restored. To clear a valid stop, stop the app and run `bun run risk:reset -- --acknowledge-paper-reset`, then restart; the command only removes the local paper latch. This persistence covers the paper process, not a funded account or an execution adapter.

The OpenCode Zen cooldown file stores only a schema version, retry timestamp, retry count, and last-request timestamp with owner-only permissions. It prevents a local restart from immediately retrying a known HTTP 429 cooldown; the API key and response body are never written.

`bun scripts/markout.ts <paper-audit.jsonl> <kuru-l2.jsonl>` measures 5s, 15s, and 60s directional price markouts for audited Jev decisions, overall and split by buy/sell action and chosen-action probability bucket. It reports decision, matched, missing, mean chosen confidence, observed positive-markout fraction, Brier score, and calibration gap for confidence with a nonzero sample count. These are descriptive estimates against the binary outcome “future directional markout > 0,” not a claim that the model is calibrated. It prefers an exact block match and can fall back only to a verified same-market, same-chain snapshot at or before the book receipt time when the midpoint matches within half a tick. It excludes forward observations across capture gaps and requires 200 matched decisions before leaving the insufficient-sample state. Deterministic 95% block-bootstrap intervals resample contiguous time blocks set to three times the longest horizon; reports suppress them below ten contributing blocks. Because a single session and even this resampling leave substantial uncertainty, intervals are exploratory diagnostics rather than formal significance tests. Passing the decision floor remains descriptive signal validation, not a fill or profitability model; serially related decisions still need broader out-of-sample evidence.
